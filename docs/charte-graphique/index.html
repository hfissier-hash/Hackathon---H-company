Ton salon en 3D, avec de vrais produits qui rentrent. Cette page fixe le logo, les couleurs, la typographie et les motifs de Nestr, pour l’appli, les decks et les documents.

1. Logo

Deux formes. Le logotype « nestr. » est la forme principale. Le monogramme « (n.)™ » sert dans les petits formats : coin de page, icône d’appli, favicon. Dans les deux, le « n » et le point ont toujours la même couleur d’accent.

2. Couleurs

Une palette de bois clair et de forêt nordique. Le pin porte la marque, le lingon (airelle) attire l’œil, le soleil sert d’accent sur fond sombre, jamais dans le logo. Contrastes calculés selon WCAG.

5. Ton

  • On tutoie. Phrases courtes, concrètes, avec des chiffres : « 230 cm », pas « un grand canapé ».
  • On rassure sans promettre : « ça rentre » se dit quand c’est mesuré.
  • Le nom s’écrit Nestr dans une phrase ; nestr. en minuscules avec le point, seulement comme logo.
